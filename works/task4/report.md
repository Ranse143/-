Анализ WEB-информационных систем
1. Анализ существующих систем
WEB-информационные системы позволяют пользователям работать с данными через браузер без установки отдельного приложения, что упрощает развертывание и обновление программного обеспечения.

На рынке представлены различные WEB-системы, каждая из которых решает определенный класс задач:

1С — автоматизация бухгалтерского учета, управления продажами, складскими запасами и предприятием в целом;
Bitrix24 — CRM-система с функционалом управления задачами, проектами и внутренними коммуникациями;
Microsoft Dynamics 365 — комплексное решение для CRM, управления продажами, ресурсами и бизнес-аналитики;
Salesforce — облачная платформа для управления взаимоотношениями с клиентами, автоматизации продаж и маркетинга.
Основные преимущества WEB-архитектуры:

централизованное хранение данных;
доступ с любых устройств, имеющих браузер;
простота обновления системы (достаточно обновить серверную часть);
возможность масштабирования.
Недостатки:

зависимость от стабильности сети;
необходимость защиты сервера и базы данных;
требуются квалифицированные специалисты для настройки безопасности.
2. Разработанное приложение
В рамках выполнения задания разработано WEB-приложение «Туристическое агентство», которое позволяет пользователям просматривать информацию о доступных турах через браузер.

Использованные технологии
Delphi 10.2 — среда разработки, использованная для создания серверной логики и генерации HTML-страниц;
Microsoft IIS — веб-сервер, обеспечивающий обработку HTTP-запросов;
Microsoft SQL Server — система управления базой данных;
FireDAC — библиотека доступа к данным для Delphi, обеспечивающая взаимодействие с SQL Server;
HTML и CSS — для формирования интерфейса и оформления страниц.
Архитектура приложения
Браузер ? IIS ? Delphi ? FireDAC ? MS SQL Server

Схема работы: пользователь отправляет HTTP-запрос через браузер, IIS принимает запрос и передает его модулю Delphi, который через FireDAC выполняет запрос к базе данных SQL Server. Результат формируется в HTML-страницу и возвращается пользователю в браузере.

Структура базы данных
База данных содержит следующие таблицы:

Countries — страны (поля: идентификатор, название);
Cities — города (поля: идентификатор, название, идентификатор страны);
TourTypes — типы туров (поля: идентификатор, название типа);
Tourists — туристы (поля: идентификатор, ФИО, контактные данные);
Tours — туры (поля: идентификатор, название, идентификатор города, идентификатор типа, дата начала, дата окончания, стоимость).
Связи между таблицами организованы через внешние ключи: города относятся к странам, туры — к городам и типам туров.

3. Возможности приложения
Приложение предоставляет следующие функции:

просмотр списка туристических туров с детальной информацией;
отображение информации о зарегистрированных туристах;
вывод справочной информации о странах и городах;
отображение типов туров;
просмотр дат поездок и стоимости туров.
Интерфейс реализован в виде набора HTML-страниц, каждая из которых представляет отдельный раздел системы.

4. Заключение
В ходе выполнения работы был проведен анализ существующих WEB-информационных систем и разработано WEB-приложение для туристического агентства. Приложение демонстрирует работу по схеме «браузер — веб-сервер — серверная логика — база данных» с использованием технологий IIS, Delphi и MS SQL Server.

Разработанное приложение может быть использовано как основа для построения полноценной информационной системы туристического агентства — в дальнейшем возможна доработка функционала (добавление бронирования, поиска, личных кабинетов) и расширение структуры базы данных.
